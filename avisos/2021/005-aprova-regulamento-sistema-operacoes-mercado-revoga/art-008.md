# Artigo 8.º (Forma de comunicação)

1. As instituições participantes devem transmitir, através do Meticalnet ou outro meio de comunicação indicado pelo Banco de Moçambique, os elementos relativos às operações que pretendem realizar através do SOM.

2. O Banco de Moçambique utiliza os meios de comunicação referidos no número anterior para anunciar as operações que se propõe a realizar e para transmitir os respectivos resultados.

3. As comunicações entre o Banco de Moçambique e as instituições participantes no SOM são, em geral, estabelecidas em tempo real através do Meticalnet, ou outro meio de comunicação indicado pelo Banco de Moçambique.

4. O Banco de Moçambique emite comprovativos das operações realizadas.
