# Artigo 5.º (Biomassa)

As tarifas a serem praticadas para a comercialização da electricidade produzida por centrais de energia da biomassa obedecem a seguinte estruturação:

a) 5,74 Mt/kWh para centrais com Capacidade Instalada de 500kW;

b) 5,46 Mt/kWh para centrais com Capacidade Instalada de 750kW;

c) 5,36 Mt/kWh para centrais com Capacidade Instalada de 1MW;

d) 5,02 Mt/kWh para centrais com Capacidade Instalada de 2MW;

e) 4,65 Mt/kWh para centrais com Capacidade Instalada de 3MW;

f) 4,56 Mt/kWh para centrais com Capacidade Instalada de 4MW;

g) 4,43 Mt/kWh para centrais com Capacidade Instalada de 5MW;

h) 4,34 Mt/kWh para centrais com Capacidade Instalada de 6MW;

i) 4,25 Mt/kWh para centrais com Capacidade Instalada de 7MW;

j) 4,15 Mt/kWh para centrais com Capacidade Instalada de 8MW;

k) 4,12 Mt/kWh para centrais com Capacidade Instalada de 9MW;

l) 4,06 Mt/kWh para centrais com Capacidade Instalada de 10MW.
