# Artigo 11.º (Consignação da Receita)

A receita resultante da taxa de exportação de madeira processada tem o seguinte destino:

a) 10% para o Orçamento do Estado;

b) 40% para fiscalização;

c) 10% para o combate as queimadas descontroladas;

d) 30% para restauração de floresta nativa (reflorestamento);

e) 10% para desenvolvimento institucional.
