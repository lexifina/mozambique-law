# Artigo 15.º (Destino dos valores das taxas e multas)

1. Os valores resultantes da cobrança das taxas têm o seguinte destino:

a) 60% para o Orçamento do Estado;

b) 20% para o Grupo Interinstitucional de Controlo de Espécies Exóticas Invasivas;

c) 20% para o FUNAB.

2. Os valores resultantes do pagamento de multas têm o seguinte destino:

a) 40% para o Orçamento do Estado;

b) 40% para o Grupo Interinstitucional de Controlo de Espécies Exóticas Invasivas;

c) 20% para o FUNAB.
