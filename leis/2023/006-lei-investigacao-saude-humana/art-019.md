# Artigo 19.º (Uso de dados de sistemas de informação de saúde)

1. Os dados de sistemas de informação podem ser usados para fins de investigação em saúde humana.

2. O uso de dados de sistemas de informação de saúde para fins de investigação em saúde humana está sujeito ao disposto nos artigos 15 e 16 da presente Lei.

3. O uso de dados de sistema de informação de saúde conformase com legislação sobre Transacções Electrónicas.
